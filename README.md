# Линия ERP — демо

Кликабельный прототип ERP для операционного управления линейным персоналом: комплектование смен, предсменный контроль, бригадир со смартфона, WorkFact, начисления, выплаты, показатели.

**Демо:** https://vvladislovv.github.io/liniya-erp/

Статичный сайт без сборки (`index.html`, `styles.css`, `app.js`, `data.js`). Все люди, компании, объекты и суммы вымышленные. Вход без пароля: выберите роль на первом экране.
